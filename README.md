# Direp

**اتوماسیون رایگان و متن‌باز دایرکت و کامنت اینستاگرام برای فروشگاه‌های ایرانی**، روی API رسمی اینستاگرام از طریق [BoxAPI](https://boxapi.ir).

Direp را روی سرور خودتان نصب می‌کنید، کلید BoxAPI خودتان را وارد می‌کنید و همه امکانات را رایگان دارید. تنها هزینه، اشتراک BoxAPI است (پلن پایه: ماهانه ۷۹۰ هزار تومان برای یک پیج، با ۷ روز آزمایش رایگان). نه کارمزد، نه اشتراک دوم، نه واسطه.

## امکانات

- **کامنت به دایرکت**: کسی زیر پست «قیمت» کامنت بگذارد، جواب کامنت و پیام دایرکت (با دکمه لینک) خودکار می‌گیرد. چند کلمه کلیدی در هر قانون، جواب‌های متنوع زیر کامنت.
- **Follow-Gate**: قیمت فقط برای فالوورها؛ بقیه اول دعوت به فالو می‌شوند. (از `follow_status` رسمی BoxAPI استفاده می‌کند.)
- **پاسخ خودکار دایرکت**: تشخیص سؤال قیمت، سایز، پیگیری سفارش، رسید پرداخت و شکایت؛ به فارسی و فینگلیش. متن هر پاسخ دست خودتان است.
- **بازیابی سبد خرید**: به کسی که قیمت پرسید و نخرید، ۲ ساعت بعد یک پیام دوستانه و ۲۰ ساعت بعد پیام دوم با کد تخفیف؛ همه داخل پنجره ۲۴ ساعته متا. با رسید پرداخت، پیگیری متوقف می‌شود.
- **هشدار در بله یا تلگرام**: شکایت مشتری، رسید پرداخت و پیگیری‌ها به گوشی شما می‌رسد. بله بدون فیلترشکن کار می‌کند.
- **فهرست مشتریان**: مرحله هر مشتری، شماره موبایلی که در دایرکت نوشته، ارسال دایرکت از پنل.
- **فارسی و راست‌چین**، بدون وابستگی به CDN خارجی (فونت وزیرمتن داخل پروژه است).

## چه چیزی لازم دارید

1. حساب [BoxAPI](https://boxapi.ir/pricing) با سرویس «API رسمی دایرکت و کامنت» و پیج اینستاگرام وصل‌شده.
2. یک سرور (VPS) با Docker، یا Node.js نسخه ۲۲.۱۳ به بالا.
3. یک دامنه با HTTPS (BoxAPI وب‌هوک را فقط به آدرس HTTPS می‌فرستد).

## نصب با Docker

```bash
git clone https://github.com/Mahdi-Khalili-Marketing/direp.git
cd direp
cp .env.example .env        # PUBLIC_URL را آدرس دامنه خودتان بگذارید
docker compose up -d --build
```

برنامه روی `127.0.0.1:3000` بالا می‌آید. آن را پشت یک وب‌سرور با HTTPS قرار دهید. نمونه با [Caddy](https://caddyserver.com) (گواهی SSL را خودش می‌گیرد):

```
direp.example.ir {
    reverse_proxy 127.0.0.1:3000
}
```

## نصب بدون Docker

```bash
npm ci
npm run build
cp .env.example .env
npm start
```

## راه‌اندازی اولیه

1. آدرس دامنه را باز کنید و حساب مدیر را بسازید (شماره موبایل و رمز). هر نصب فقط یک مدیر دارد.
2. در تب «اتصال پیج»، کلید BoxAPI را از پنل BoxAPI، بخش «تنظیمات API» وارد کنید و پیج را انتخاب کنید.
3. «آدرس وب‌هوک» نمایش‌داده‌شده را در پنل BoxAPI، بخش «تنظیمات API»، قسمت Webhook ثبت کنید.
4. (توصیه‌شده) در پنل BoxAPI یک Webhook Secret بسازید و همان را در Direp هم وارد کنید تا امضای هر پیام بررسی شود.
5. در تب «کامنت به دایرکت» اولین قانون را بسازید.

## نکته‌های مهم

- **پنجره ۲۴ ساعته متا**: به مشتری فقط تا ۲۴ ساعت بعد از آخرین پیامش می‌شود پیام داد. Direp خارج از این بازه پیامی نمی‌فرستد.
- **Private Reply** (دایرکت درباره کامنت) فقط تا ۷ روز بعد از کامنت ممکن است.
- **Follow-Gate** ناهمزمان است: BoxAPI جواب فالو را با وب‌هوک می‌فرستد. اگر تا ۲ دقیقه جوابی نرسد، Direp پیام اصلی را می‌فرستد تا مشتری بی‌جواب نماند (`FOLLOW_CHECK_TIMEOUT_SECONDS`).
- ربات قیمت واقعی محصولات شما را نمی‌داند. متن پاسخ‌ها را در تب «پاسخ خودکار دایرکت» مطابق فروشگاه خودتان بنویسید.

## امنیت

- کلید BoxAPI و توکن ربات فقط روی سرور شما ذخیره می‌شوند و هیچ‌وقت به مرورگر برنمی‌گردند.
- وب‌هوک یا با امضای HMAC رسمی BoxAPI بررسی می‌شود، یا با کلید تصادفی داخل آدرس؛ هیچ‌وقت باز نیست.
- پیام‌های تکراری BoxAPI (retry) با `event_id` شناسایی می‌شوند تا به مشتری دو بار جواب داده نشود.
- رمز عبور با scrypt ذخیره می‌شود؛ تغییر رمز همه نشست‌های قبلی را باطل می‌کند.

## پشتیبان‌گیری و به‌روزرسانی

همه داده‌ها در یک فایل SQLite است: `data/direp.db`. برای پشتیبان‌گیری همین پوشه را کپی کنید.

```bash
git pull && docker compose up -d --build
```

## توسعه

```bash
npm install
npm test          # تست‌ها
BOXAPI_DRY_RUN=true npm run dev
```

با `BOXAPI_DRY_RUN=true` هیچ پیامی واقعاً به اینستاگرام ارسال نمی‌شود.
